# Kieswijzer: Expat IVR & Phone Tree Navigator

A lightweight, zero-dependency visual directory designed to help expats, internationals, and non-Dutch speakers navigate automated Dutch phone trees (*keuzemenu's*).

### What It Does
* **Visual Decision Trees:** Step-by-step maps of automated phone systems for major Dutch public services, healthcare providers, and utilities.
* **Bypass Shortcuts:** Quick-dial sequences, direct extensions (*doorkiesnummers*), and keypad shortcuts to reach human operators faster.
* **Phonetic Audio Guides:** Pronunciation tips and native audio prompts for essential Dutch speech-recognition keywords (e.g., *Medewerker*, *Apotheker*, *Spoed*).
* **Interactive Call Simulator:** A sandboxed keypad to practice navigating Dutch menu prompts without live-call pressure.
